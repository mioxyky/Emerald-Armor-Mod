# Texture folders

Binary placeholder PNG files are intentionally not committed in this workspace so GitHub/Codex text extraction can work without binary-file errors.

Add your own PNG textures before running the mod in-game.

## Item textures

Put these files in `item/`:

- `emerald_helmet.png`
- `emerald_chestplate.png`
- `emerald_leggings.png`
- `emerald_boots.png`
- `emerald_sword.png`
- `emerald_pickaxe.png`
- `emerald_axe.png`
- `emerald_shovel.png`
- `emerald_hoe.png`

## Worn armor textures

Put these files in `models/armor/`:

- `emerald_layer_1.png`
- `emerald_layer_2.png`
